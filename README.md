# The_Odin_Project
O Projeto Odin fornece um currículo gratuito de codificação de código aberto que pode ser tomado inteiramente online. Desde a sua criação, ajudou muitos estudantes a serem contratados como desenvolvedores e ajudou inúmeros outros em aprender programação suficiente para trabalhar em seus próprios projetos pessoais. 
Acesso: [https://www.theodinproject.com](https://www.theodinproject.com)

### Project: Bubble Sort

Objective: ***Build a method #bubble_sort that takes an array and returns a sorted array. It must use the bubble sort methodology***
![](https://upload.wikimedia.org/wikipedia/commons/c/c8/Bubble-sort-example-300px.gif)

Example:

~~~ruby
> bubble_sort([4,3,78,2,0,2])
=> [0,2,2,3,4,78]
~~~
